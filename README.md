# 学生成绩管理系统

## 项目简介

一个基于 C++ 控制台的学生成绩管理系统，支持学生信息的增、删、改、查、文件存储及多种排序算法。适合学习 C++ 基础语法、文件 I/O、STL 容器及算法思想的练手项目。

## 功能列表

| 编号 | 功能           | 说明                             |
|------|----------------|----------------------------------|
| 1    | 添加学生信息   | 学号、姓名、成绩，学号自动判重   |
| 2    | 删除学生记录   | 按学号删除，需二次确认           |
| 3    | 修改学生成绩   | 按学号修改，显示原成绩并确认     |
| 4    | 显示所有学生   | 表格形式显示，并附带统计信息     |
| 5    | 查找学生信息   | 支持按学号、姓名、成绩区间查找   |
| 6    | 保存数据到文件 | 将内存数据写入 `students.txt`    |
| 7    | 从文件加载数据 | 启动时自动加载，也可手动加载     |
| 8    | 清空当前数据   | 清空内存中的学生记录             |
| 9    | 学生数据排序   | 按学号/姓名/成绩，升序/降序，冒泡/快速排序 |
| 10   | 退出系统       | 退出程序                         |

## 技术栈

- **语言**：C++17
- **标准库**：iostream, vector, string, fstream, algorithm
- **编码**：UTF-8（Windows 控制台适配）
- **平台**：Windows（可跨平台，但清屏命令需调整）

## 安装与运行

### 环境要求

- Windows / Linux / macOS
- C++ 编译器（支持 C++17），如 g++、clang 或 MSVC

### 编译与运行

1. 克隆仓库：

   ```bash
   git clone git@github.com:SSStttudy/StudentsGradeManagement.git
   ```

2. 编译：

   **Windows (MinGW)：**

   ```bash
   g++ StudentGradeManagementSystem.cpp -o student_system.exe -std=c++17
   ```

   **Linux/macOS：**

   ```bash
   g++ StudentGradeManagementSystem.cpp -o student_system -std=c++17
   ```

3. 运行：

   **Windows：**

   ```bash
   student_system.exe
   ```

   **Linux/macOS：**

   ```bash
   ./student_system
   ```

   **注意：** Linux/macOS 下请将代码中的 `system("cls")` 替换为 `system("clear")`，并移除 Windows 编码设置部分。

## 代码亮点

- **输入验证**：`getValidInt()` 和 `getNonEmptyString()` 确保用户输入合法。
- **数据持久化**：通过 `saveToFile()` / `loadFromFile()` 实现文件存储。
- **多种排序算法**：支持冒泡排序和快速排序，可按不同字段及顺序排序。
- **查找灵活**：支持按学号精确查找、按姓名模糊查找、按成绩区间查找。
- **跨平台兼容性提示**：代码中已对 Windows 控制台编码进行适配，Linux/macOS 可简单修改。
